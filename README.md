# e-plantShopping — Paradise Nursery

## About the Project

Paradise Nursery is a plant-shopping web application built using React. It provides a simple interface for exploring plants and managing selected items in a shopping cart.

## Features

* Attractive landing page with a Get Started button.
* Navigation bar for the home page, plants page, and shopping cart.
* Plant listings with product information.
* Add-to-cart functionality.
* Shopping cart for reviewing selected plants.
* Responsive and user-friendly interface.

## Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Redux Toolkit (for state management, where implemented)

## Getting Started

### Prerequisites

Install Node.js and npm before running the project.

### Installation

Clone the repository:

```bash
git clone https://github.com/abuj-kadambari-bot/e-plantShopping.git
```

Navigate to the project directory:

```bash
cd e-plantShopping
```

Install dependencies:

```bash
npm install
```

Build the application:

```bash
npm run build
```

Start the preview server:

```bash
npm run preview
```

Open the application using the preview URL or the lab's application launcher.

## Project Structure

The project contains React components, stylesheets, and configuration files used to build the plant-shopping application.
